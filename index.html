☁ Cloud Storage (Cloudinary)

Stratum uses Cloudinary to store your files securely online — completely free up to 25GB. You only need a free Cloudinary account. Files are stored at permanent URLs, so you can always access them.

Setup: Go to cloudinary.com → Free account → Settings → Upload → Add upload preset → set to "Unsigned" → copy preset name and cloud name here.
